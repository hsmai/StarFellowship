# ⑦ Ghost(유령 박스) 현상 해결 — 진행 중

**문제**: 물체가 화면에 없는데 빈 공간·로봇 손에 3D 박스가 남는 현상.

**원인 분석(완료)**: 두 유형 —
(a) 꼬리 전파: 마지막 실검출 이후 추적 창이 에피소드 끝까지 관성으로 남음
(b) 검출 오류: 검출기가 로봇 손을 물체로 확신을 갖고 잡음

**해결(완료분)**: (a)는 오프라인 후처리로 제거 — 마지막 실검출 이후의 전파만 자르므로
정상 구간은 구조적으로 손상 불가. 13유닛 531프레임 제거.
전량 결과: `results/최종결과_ghost트리밍/`, 코드: `pipeline/postprocess.py` (ghosttrim 명령)

**이 폴더**: 51개 전후 쌍을 전량 육안 대조해 통과한 것 중 유닛별 대표 9쌍.
파일명 NN_유닛_상황_개선전/개선후 — 같은 번호끼리 같은 프레임.

**남은 것**: (b) 검출 오류형은 후처리로 구분 불가 → 다음 주 SAM 3 교체 실험에서 해결 시도.
크기 필터는 정상 유닛을 깨뜨려(오레오 144중 69프레임 손실) 채택하지 않았음.
