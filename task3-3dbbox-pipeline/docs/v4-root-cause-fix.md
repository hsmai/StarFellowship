# V4 — 근본 원인 수정 (2026-08-03 라운드2)

라운드1 육안 검증에서 5가지 증상이 지적됐다. 5개 에이전트가 frames.json 7,901프레임을
전수 분석해 원인을 특정하고, 3명의 리뷰어가 오버피팅·회귀·완결성 관점에서 교차 검증했다.

## 진단 — 증상 5가지는 같은 뿌리의 다른 단면

| 사용자 지적 | 실측된 원인 |
|---|---|
| head에서 물체 옮길 때 박스 소실 | 기각 사유의 66%가 "박스가 **커져서**"(손이 마스크에 포함). 가려짐 = 축소라는 전제가 틀렸다 |
| wrist에서 물체가 화면을 채우면 박스 없음 | 2D 면적비 상한 0.12에 걸림. 면적은 거리²에 반비례해 head(z≈0.8m)와 wrist(z≈0.2m)에서 **100배 차이** |
| wrist에서 물체가 안 보이는 손에 유령 박스 | 첫 오검출이 트랙을 시작하면 저임계 재검출·전파가 자기를 무한 강화. wrist 승인의 81%가 redet/prop |
| A/B 차이 없음 | 전체 프레임의 **38%가 박스 자체가 없고**, 그 구간에서 amodal 호출 0회. 게이트 통과 후에만 호출되는 구조 |
| HE에서 물체를 아예 못 잡음 | `np.roll` 랩어라운드 버그 — 화면 끝 물체가 반대편 depth를 읽음(재투영 오차 du=+606px). 그 쓰레기 박스가 이력을 오염시켜 나머지 130프레임 전멸 |

공통 뿌리는 셋이다.
1. **판정 기준이 스케일 가변량**이었다 (면적비·축별 크기). 카메라 거리와 물체 자세에 의존.
2. **이력이 자기를 오염**시켰다. 승인분을 무비판 갱신 → 가려진 박스가 기준을 끌어내림
   (실측: 이력 부피 1020→9cm³ 붕괴 트랙 존재).
3. **판정이 이진값**이라 복구 경로가 없었다.

## 수정

| # | 내용 | 왜 일반화되나 |
|---|---|---|
| R1 | `align_mask_to_depth`의 `np.roll` → **zero-fill 시프트** | 순수 버그. 임계값 없음, Brainco(dx=0)는 no-op |
| R2 | 면적비 상한 → **깊이 정규화 물리 크기**(0.75m) | 물리 크기는 카메라 거리에 불변. 같은 값을 head/wrist에 쓸 수 있다 |
| R3 | **재투영 자기정합** 검사 신설 | 핀홀 모델상 반드시 성립하는 불변량. 어휘·태스크 무관 |
| R4 | 축별 크기 게이트 → **회전불변 대각**, 라벨별 크기 사전 폐기 | AABB 변 길이는 회전만으로 √3배 변한다. 대각은 불변 |
| R5 | **그린다**와 **이력 갱신**을 분리 | 자기참조 루프 차단. 관측 품질로만 자격 판정 |
| R6 | 트랙 **confirmed/coasting** 상태, amodal을 게이트 밖으로 | 미확정 트랙은 저임계·전파 금지(유령 차단). coasting 구간은 B가 채움 |
| R7 | 가려짐 판정을 **물리적 증거**로 (손 마스크 겹침 + 물체 앞 픽셀 비율) | 부피 감소는 잡음(프레임간 z 변동 p90 1.62배). 마진도 물체 두께의 절반으로 상대화 |
| R8 | 모든 프레임에 진단량 기록 (기각·후보없음 포함) | 다음 라운드에서 임계를 데이터로 정하기 위한 계측 |
| R9 | 프롬프트에 **고정 방해물 어휘** 자동 추가 | 로봇 손/사람 손은 G1 데이터의 물리적 상수. 태스크 지식이 아니다 |
| R10 | `fit_box3d`를 극값 → 축별 1% 백분위 | 극값은 점 1개로 결정돼 잡음이 크고 그 잡음이 게이트에 실린다 |

**손/팔 겹침 배제**: target 후보가 손·팔 후보와 IoU 0.75 넘게 겹치면 배제한다.
"손으로 이미 설명되는 영역은 조작 대상이 아니다"는 원리이고, 손에 쥔 물체는
부분적으로만 겹치므로(IoU<0.5) 살아남는다. 라운드1의 charger 오검출(팔 전체)이 이 경로로 걸린다.

## 리뷰 반영 사항

3명의 리뷰어가 모두 `needs_revision`을 냈고, 다음을 반영했다.

- **홀드아웃 오염**: `BC_EP=5` 상수 고정이라 "다른 에피소드에서 되는가"를 측정할 수 없었다.
  → 에피소드를 환경변수로 인자화하고, **파라미터 결정에 쓰지 않은 에피소드**(Brainco ep17,
  HE 대표+7)로 별도 라운드(`r2h`)를 함께 돌린다.
- **`MAX_SIZE_GLOBAL=1.0m`은 폭발 창구**: head 작업거리에서 0.71~0.93m 박스가 통과한다
  → 0.80m로 낮춤(라운드1 승인분 최대 0.345m이라 회귀 없음).
- **`diag<0.5x` 하한이 가려짐 구간 전용 킬러**: 걸리는 83건이 100% 가려짐 프레임
  → 하드 기각에서 빼고 **이력 갱신 자격**으로만 사용.
- **`det_budget` 고정 3초는 정상 head를 자름**(9/16 에피소드) → 트랙이 실측한 det 간격
  중앙값의 3배로 유도.
- **`confirmed`를 det 2회로만 두면 HE Articulated가 0이 됨**(det 평생 1회)
  → `det 2회` 또는 `det 1회 + 정합 redet 3회`로 완화.
- **가림 depth 마진 3cm는 두꺼운 물체에서 상시 오탐** → 물체 자기 두께의 절반으로 상대화.
- **ry 밴드는 rx와 달라야 함**(실측 rx 0.90~0.97 vs ry 0.61~0.78) → 축별로 분리.
