# V5 — 라운드3 개선 (2026-08-03)

라운드2 육안 검증에서 13개 항목을 지적받았다. 6개 에이전트가 frames.json 15,313프레임을
전수 분석하고 3명의 리뷰어가 회귀·오버피팅·완결성 관점에서 교차 검증했다.

## 진단 — 네 갈래 문제와 그 뿌리

### 1. 유령 잔존 (사용자 최우선 지적: "이것만 고치면 완벽")

"물체가 시야에서 사라질 때 3d box도 사라져야 하는데 공백에 작게 남는다"

**원인**: 마스크 전파(`prop`)가 **자기 출력으로 자기 탐색창을 갱신**하는 닫힌 고리였다.
마스크가 창을 다 못 채우면 창이 프레임당 0.97배로 줄어 복리로 붕괴한다.

| 실측 | |
|---|---|
| 탐색창 면적 | 161,839px² → 2,112px² (85프레임) |
| 유령 프레임 | 방식 A 승인 9,579 중 **721 (7.5%)** |
| 유령 트랙 13개 중 | **12개가 wrist 카메라** — 사용자 지적과 일치 |
| 감시견 도달 | `accept()`가 src 무관하게 miss를 0으로 되돌려 **불가능** (180프레임 내내 confirmed) |

**수정**: 탐색창을 **마지막 실검출에 앵커링**한다. 되먹임 고리 자체를 끊으므로 임계값이 필요 없다.
전파 프레임은 검출 예산을 소모하고, 유령 신호(마스크 붕괴·경계 접촉·깊이 이탈)가
동반될 때만 기각한다.

### 2. 방식 B가 실제보다 작다

**원인**: 승인 7,232프레임 중 이력에 반영된 것이 **972건(13.4%)뿐**이고,
**6,143건(84.9%)이 가림 판정 하나로 차단**됐다. 가림 판정의 결함 셋:
- 기준 깊이가 낡음 (손이 화면 밖인데 `occluder_frac` 0.81로 포화)
- 판정 영역이 박스 전체 (물체는 박스의 47%만 차지)
- 이진 차단 (조금이라도 가리면 이력에서 완전 배제)

**수정**: 기준 깊이를 최근 실검출 중앙값으로, 마진을 **추세 제거 후 잔차**에서 유도,
이력 차단을 `occ_frac >= 0.5`로 완화. 방식 B의 크기 기준을 중앙값에서 **상위 75분위**로.
추가로 단일 시점의 두께 결손을 **거울 보정**으로 복원한다(방식 B 전용).

### 3. 화면을 크게 채우면 못 잡는다 (apple·doll·tissue 손목)

**원인**: 픽셀 면적 상한(화면의 60%). 실측상 면적 기각 154건이 **전부 wrist, head는 0건**.

**수정**: 면적비를 버리고 **깊이 정규화 물리 크기**만 쓴다. 거리에 불변이라 카메라가 달라도 성립.

### 4. 회귀 5건은 검출 자체가 0

방해물 어휘를 프롬프트에 합치면서 target이 밀렸다. **프롬프트에서 제거**하고,
가림 판정은 depth만으로 수행한다.

### 5. 얇은 부속물 누락 (토끼 귀, 꽃 줄기)

**원인**: `largest_component`가 얇게 이어진 부분을 별개 덩어리로 보고 잘라냈다.

**수정**: **깊이가 비슷한 성분들의 합집합**(`same_depth_components`)으로 교체.
케이블처럼 깊이가 다른 부속물은 여전히 배제되고, 손처럼 큰 성분은 면적 제한으로 배제한다.

### 6. PickDrink 라벨 오류 (확인됨)

공식 지시문은 `"Pick up the red cup on the table."`이지만 **영상 실물은 파란 뚜껑의 투명 물병**이다.
라운드1에서 `5×4×2cm`로 잡힌 건 뚜껑만 잡은 것이었다.

→ 지시문 어휘를 그대로 믿으면 안 된다는 사례다. **지시문 어휘 + 상위 개념 어휘**를 함께 넣는다.
HE 246개 태스크에도 같은 불일치가 있을 수 있다.

## 리뷰에서 되돌린 것

리뷰어 3명이 모두 `needs_revision`을 냈고 다음을 반영했다.

| 지적 | 반영 |
|---|---|
| 전파에 **무조건 시간 예산**을 걸면 정상 구간이 대량 삭감 (Tool_use 0.99→0.41) | 유령 신호와 **결합된 조건부**로 변경 |
| **정체성 실패**로 기각한 후보로 앵커를 갱신하면 로봇 팔이 앵커가 됨 (PickCharger 109프레임) | 정체성/품질 실패를 나눠 앵커 갱신을 품질 실패로 한정 |
| 가림 마진을 MAD로 유도하면 물체가 움직일 때 '추세'를 잡음으로 오인 | **추세 제거 후 잔차**에서 유도 |
| 방식 B가 무한히 이어질 수 있음 | `COAST_SEC=2.5초` 상한 신설 |
| `n_history 100개`는 `HIST=30` 때문에 불가능 | HIST를 40으로 올리고 지표를 이력 갱신률로 변경 |

## 품질 게이트 (대규모 실행 대비)

사용자의 최대 우려 — "모든 에피소드에서 이 품질이 나온다는 보장이 없다" — 에 대한 답으로,
**정답 없이 에피소드 품질을 자동 판정**하는 지표를 설계했다.

| 신호 | 판별력 |
|---|---|
| `coverage_det` | 전파 승인을 제외한 실관측 커버리지 |
| `max_gap_s` | 연속 미승인 최장 구간(초). AUC 0.99 — 단일 신호 중 최강 |
| `peer_ratio` | 같은 물체의 다른 카메라 대비 크기비. head 2대가 1.00~1.14배로 일치, 불량은 1.65~4.37배 (**겹침 0**) |
| `det_margin` | `median(det_score) - 0.35`. 74개 클래스 중 30개가 여유 0.07 이내 — 선행 지표 |
| `ghost_frames`, `max_prop_run` | 코드 회귀 감시선 |

**3분류**: TRUST(위반 0) / SUSPECT(1~2) / REJECT(3+ 또는 핵심 규칙 위반).
사람은 SUSPECT만 태스크당 최대 2건 표본 검토한다.
