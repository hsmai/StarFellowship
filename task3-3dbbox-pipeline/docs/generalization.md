# 일반화 전략 — 전 데이터셋 적용을 위한 준비

> 현재는 **태스크당 에피소드 1개**로 검증한 상태다. 전체 데이터(Brainco 1,598 +
> HE g1 4,064 에피소드)에 적용할 때 같은 품질이 나오도록 준비한 내용을 기록한다.

## 1. 무엇이 일반화의 위험인가

15개 샘플에서 눈으로 맞춘 값은 다른 에피소드에서 깨진다. 실제로 겪었다.

| 사례 | 내용 |
|---|---|
| 화면 점유율 상한 0.12 | 머리 카메라(0.8m)에서 정한 값인데, 손목 카메라(0.2m)는 **같은 물체가 100배 크게 보여** 정상 물체가 잘렸다 |
| 점군 필터 완화 | 얇은 부속물을 살리려 완화했더니 배경·로봇팔이 들어와 charger가 6×6×2 → 8×28×30cm가 됐다 |
| 지시문 신뢰 | PickDrink 지시문은 "red cup"이지만 **실물은 물병**이었다 |

## 2. 설계 원칙 — 판정 기준을 스케일 불변량으로

카메라 거리나 물체 자세에 의존하는 양으로 판정하면 반드시 깨진다.

| 바꾼 것 | 왜 |
|---|---|
| 화면 면적비 → **깊이 정규화 물리 크기**(m) | 물리 크기는 거리에 불변. 머리·손목에 같은 값을 쓸 수 있다 |
| 축별 크기 비교 → **회전불변 대각** | AABB 변 길이는 회전만으로 √3배 변한다 |
| — → **재투영 자기정합** | 핀홀 모델상 반드시 성립하는 불변량. 어휘·태스크와 무관 |
| 라벨별 크기 사전 → **폐기** | 246개 태스크 규모에서 유지 불가능한 하드코딩 |
| 부피 감소로 가림 판정 → **손 마스크 겹침** | 부피는 잡음이 크다(프레임 간 깊이 변동 1.6배) |

## 3. 태스크별 프로파일 — 국소화

한 태스크를 고치려고 전역 값을 바꾸면 다른 태스크가 깨진다.
그래서 **문제가 있는 태스크에만** 설정을 건다.

- 신규 옵션의 기본값은 전부 **비활성**이다. 지정하지 않은 태스크는 코드 경로가 동일하다.
- GraspOreo·GraspRubiksCube는 override가 0개다. 이 둘의 결과가 이전 라운드와 일치하는지로
  **변경의 무해성을 검증**한다(r6에서 25건 전부 일치 확인).

## 4. 대량 실행 시 품질 확인

정답이 없으므로 자동 지표로 **사람이 볼 표본을 고른다.**

| 신호 | 의미 |
|---|---|
| `coverage_det` | 전파(추정) 승인을 제외한 실관측 비율 |
| `max_gap_s` | 연속 미승인 최장 구간(초) |
| `peer_ratio` | 같은 물체의 다른 카메라 대비 크기비. 정상 1.00~1.14배, 불량 1.65~4.37배 |
| `det_margin` | 검출 점수 여유. **위험 태스크 사전 식별**에 쓴다 |

**중요 — 이 지표로 파라미터를 자동 조정하지 않는다.**

> "화면의 12% 이상이면 오검출"이라는 지표가 손목 카메라에서 **정상 물체를 잘라냈다.**
> 손목은 근접 촬영이라 물체가 화면을 채우는 것이 정상이다.

지표 자체가 틀릴 수 있으므로, 품질 판정의 최종 근거는 **육안 검증**이다.
지표는 수천 개 에피소드 중 무엇을 볼지 고르는 용도로만 쓴다.

## 5. 전 데이터 적용 절차 (계획)

1. **robustness 검증** — 태스크당 3~5 에피소드로 254개 태스크 전부 실행(4.5~7.4시간).
   태스크당 1개에서 3~5개로 늘려 에피소드 간 편차를 본다.
2. **위험 태스크 식별** — `det_margin`이 낮은 태스크를 목록화해 우선 검토한다.
3. **본 실행** — `fast` 프리셋(3fps, 머리 1대) 기준 25시간. 필요에 따라 조정.
4. **표본 검토** — 자동 분류에서 '의심'으로 나온 것만 태스크당 2건씩 육안 확인.

## 6. 남은 과제

| 항목 | 내용 |
|---|---|
| HE target object 목록 | 246개 태스크의 description을 훑어 실제 대상 물체 목록을 만든다. PickDrink처럼 **지시문과 실물이 다른 경우**를 사전에 걸러야 한다 |
| HE intrinsics | 메타에 없어 FOV 70° 가정. 이 값이 틀리면 3D 크기가 상수배로 어긋난다 |
| 손목 카메라 | 물체가 화면을 가득 채우면 3D box가 의미를 잃는다(doll·tissue). 제외할지 검토 필요 |
| 얇은 물체 이동 구간 | charger·toothpaste는 옮겨지는 동안 검출이 끊긴다. 방식 B가 위치를 추정해 덮지만, 방식 A로는 원리적 한계 |
