# 파이프라인 최종 실행 결과

`pipeline/run_review.py`로 두 데이터셋의 **모든 태스크 종류 15종(39유닛)**을 검증한 결과입니다.
(서버 실행 시 산출 폴더명은 자유 인자이며, 여기 저장된 것이 최종 채택본입니다)

```
최종결과/
├── brainco/<태스크>_ep5/<카메라>/   유닛별 결과
│     stats.json      검출률·크기 통계
│     boxes2d.json    프레임별 2D 박스 (신규 task ①의 산출물)
│     AB_compare.png  방식 A|B 비교 스틸
│     (A_visible.mp4, B_amodal.mp4, frames.json 은 용량 문제로 저장소 제외
│      — 구글 드라이브 공유본 참조)
├── he/<카테고리>_ep<N>/             동일 구성
└── 미리보기_*.png                   전체 유닛 격자 미리보기

최종결과_ghost트리밍/
└── (동일 구조, 13유닛)              유령 박스 꼬리를 후처리로 제거한 재렌더.
      trim_report.json               라벨별 제거 프레임 수
```

- 방식 A = 보이는 부분만 / 방식 B = 가려진 부분까지 추정. 상세는 최상위 README.
