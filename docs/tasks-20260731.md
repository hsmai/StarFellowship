## Task 3. Unitree G1 데이터 3D Bounding Box 추출 파이프라인 (1·2번 이후)

대상: G1 Brainco 8종 + Humanoid Everyday (이미 다운로드 완료된 데이터)

### 파이프라인 (RoboBrain의 Pseudo-3D Object Annotation Pipeline)

| 단계 | 모듈 | 역할 |
|---|---|---|
| 0 | RGB 프레임 | 입력: G1 Brainco 4뷰 / Humanoid Everyday / AgiBot World |
| 1 | **GroundingDINO** | 텍스트 프롬프트로 객체 2D bounding box 검출 (open-vocab) |
| 2 | **SAM 2.1** | 박스를 프롬프트로 인스턴스 마스크 추출 + 프레임 간 추적 |
| 3 | **UniDepthV2 + WildCamera** | 메트릭 depth 추정 + 카메라 intrinsics 복원 (2D→3D) |
| 4 | **Back-projection** | 마스크와 depth를 intrinsic matrix로 객체별 point cloud 복원 |
| 5 | **3D Bounding Box** | 점군에서 axis-aligned 3D box 산출 |

- 참고 문헌: RoboBrain 2.0 / 2.5 Technical Report (파이프라인 구성 논문들 상세 기술)
- 산출물: 데이터 1개(에피소드 1개)에 대해 추출 결과를 눈으로 확인 가능한 시각화

### 참고 사항

- **Humanoid Everyday는 실측 depth가 이미 있음** → 3단계(depth 추정)를 건너뛰고 실측 depth로 back-projection 가능. 단 intrinsics가 메타에 없어 WildCamera 복원 또는 저자 데이터로더 확인 필요. 추정 depth와 실측 depth 비교 검증도 가능
- **Brainco는 depth가 없으므로** 파이프라인 전 단계 필요. 4뷰 중 head 카메라 기준 진행이 자연스러움

### GPU 리소스 (개략 추정치, 착수 시 정밀 확인)

| 모듈 | VRAM (추론) |
|---|---|
| GroundingDINO (Swin-T/B) | 4~6GB |
| SAM 2.1 (hiera-L) | 6~8GB |
| UniDepthV2 (ViT-L) | 6~10GB |
| WildCamera | 2~4GB |

→ 순차 실행 시 **단일 GPU 16~24GB(RTX 3090/4090, A5000급)면 충분**. 배치/추적 포함 동시 로드 시 24GB 권장.
